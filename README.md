# 声刻 · 本地中文声音克隆

在 Apple 芯片 Mac 上保存参考音色、输入中文文案，并生成可试听及下载的 MP3。网页服务只监听 `127.0.0.1`，这个地址始终指向**正在使用的那台电脑**。每台 Mac 独立选用自己的端口；GitHub 代码不会连接到仓库作者的电脑。可在 Qwen3-TTS 1.7B Base 8-bit 与 OmniVoice 官方模型之间切换。

首次运行会在使用者自己的 Mac 上下载依赖和模型，模型文件约需数 GB 空间。VoiceStudio、OmniVoice 与 GPT-SoVITS 的区别及实测记录见[模型切换方案](docs/模型切换方案.md)。OmniVoice 权重仅限非商业使用。

## 启动

双击 [启动声刻.command](启动声刻.command)。首次启动会下载模型并安装 macOS 后台服务，之后即使退出 Codex，服务也会继续运行，并在登录 Mac 后自动启动。脚本会自动打开**本机**网页；所选端口只保存在本机被 Git 忽略的 `data/local-port`。之后启动不需要重新下载。

另一台 Apple 芯片 Mac 可以在终端执行（首次需已安装 [uv](https://docs.astral.sh/uv/getting-started/installation/) 或 Homebrew）：

```bash
git clone https://github.com/magmddljlj/shengke-local-voice-studio.git && cd shengke-local-voice-studio && ./启动声刻.command
```

## 使用

网页顶部提供多段可切换的日常朗读稿。点“换一段”可更换范本，并同步更新空白或仍等于旧范本的“录音原文”；用户已经手动填写的转写内容会保留。让朗读者用自然语气只读正文，结束后停一秒；再上传录好的文件。若实际读法与范本不同，必须按录音修改文字。范本包含平常叙述和问句，用来采集较自然的声音变化；它不保证对所有模型或每个人都达到最佳相似度。

1. 准备人物本人或已获授权的清晰录音。可在“音色库”按住录音、松开结束（也可点按开始/结束），试听后保存；或上传已有 MP4、MOV、WAV、MP3、M4A。单人说话，没有背景音乐。
2. 在右侧输入音色名称，上传文件，并逐字填写**前 15 秒**里实际说的话。视频会自动提取前 15 秒声音；只填标题或整段视频的摘要会影响克隆质量。保存后音色会留在本机。
3. 左侧选音色和声音模型，输入中文文案，点击“生成 MP3”。OmniVoice 首次生成或从千问切回时需重新加载，实测可能等待约 1～2 分钟；保持使用 OmniVoice 时后续短句约 10 秒。
4. 在“生成记录”逐条试听原声与两种模型的结果、下载 MP3。音色库的原录音和生成记录里的“对照原声”都有可暂停、可拖动进度的播放器；播放另一段时，上一段会自动暂停。默认显示最新 5 条，可以展开旧记录，也可以单独删除某条记录及其本机 MP3。再次生成不会覆盖旧记录，重启后历史和音色仍在。

录音、音色资料与生成的 MP3 保存在 `data/`，模型保存在 `.cache/`，均被 Git 忽略。即使服务停止或 Codex 关闭，`data/` 中的资料也不会因此删除。日志保存在 `data/logs/`。如果发现有 MP3 文件但缺少对应记录信息，网页会把它作为“找回的音频”列出供试听和下载，并说明缺失的资料，不会猜测文案或模型。页面提供删除音色与生成记录；删除生成记录会同时删除对应的本机 MP3。每次生成最多 500 字，长文建议分段。每次生成的 MP3 都会经过解码校验；音色像不像、语气自然不自然仍需试听。

网页直接录音使用浏览器麦克风，需要允许麦克风权限。本机自动打开的网页可以录音；手机直接访问 Mac 的局域网 HTTP 地址通常不满足浏览器的安全要求，且当前服务只监听本机地址。手机直录要先建立受保护的 HTTPS 访问入口，目前尚未完成手机真机验证。

## 代码备份与部署边界

GitHub 仓库只保存代码，不包含模型、录音、音色资料、生成的 MP3 或本机端口配置。当前版本依赖 Apple 芯片 Mac、本地 Qwen/OmniVoice 模型，只监听本机回环地址；克隆与生成都在安装者自己的电脑上运行。

热铁盒的[自动部署](https://docs.retiehe.com/host/auto-deploy.html)面向前端项目，其 [Python 云函数](https://docs.retiehe.com/host/python-cloud-function.html)目前不支持安装 `pip` 依赖。因此不能把当前后端和 MLX 模型直接部署到热铁盒。仅托管现有网页会让上传和生成按钮无法工作，暂不发布这种页面。若以后需要外网使用，需另选支持模型推理的服务器并重新设计身份验证、录音存储和前后端连接，再接入热铁盒前端。

## 已验证与待验证

已在 M5、16 GB Mac 上验证 MP4 视频上传与提取、音色保存、两个模型用同一音色同一中文文案生成 MP3、网页切换模型、切回千问、生成记录重启复用和文件解码。用离线识别粗查了两条 OmniVoice 短句，识别出了主要内容，但同音字仍可能被误认。**真实人声音色的相似度和自然度仍需用户试听判断。**
